01 · DOM-manipulatie

Selecteren, aanpassen, maken en verwijderen

Deze opdracht oefent querySelector, getElementById, textContent, innerHTML, style, createElement, appendChild en remove.

Original heading

Some text.

JavaScript

Wat gebeurt er?

// Selecteer bestaande elementen uit de DOM.
const title = document.querySelector("#demo-title");
const description = document.getElementById("demo-description");
const output = document.querySelector("#output");

// Pas bestaande inhoud en opmaak aan.
title.textContent = "Hello World!";
description.innerHTML = "De DOM is <strong>dynamisch</strong>.";
title.style.color = "#076d69";

// Maak een nieuw HTML-element in het geheugen.
const p = document.createElement("p");
p.textContent = "Dit element is met JavaScript gemaakt.";

// Voeg het nieuwe element toe aan de pagina.
output.appendChild(p);

// Later kun je hetzelfde element weer verwijderen.
p.remove();

02 · Productenpagina

Data renderen en sorteren

De producten staan niet in de HTML. JavaScript rendert de array met forEach en createElement. De knoppen sorteren op prijs of populariteit.

JavaScript

Eén array, meerdere acties

// JavaScript-array met objecten (data in de applicatie).
const products = [
  { naam: "Koffie", prijs: 3.20, populariteit: 92 },
  { naam: "Thee", prijs: 2.80, populariteit: 71 },
  { naam: "Croissant", prijs: 3.75, populariteit: 88 },
  { naam: "Brownie", prijs: 4.25, populariteit: 84 },
  { naam: "Sandwich", prijs: 6.50, populariteit: 79 },
  { naam: "Sap", prijs: 3.95, populariteit: 67 }
];

function renderProducts(items) {
  productList.innerHTML = ""; // Eerst oude weergave leegmaken.
  items.forEach((product) => {
    const card = document.createElement("article");
    card.className = "product-card";
    // Maak inhoud en voeg de kaart toe aan de DOM.
    productList.appendChild(card);
  });
}

sortPrice.addEventListener("click", () => {
  products.sort((a, b) => a.prijs - b.prijs);
  renderProducts(products);
});

sortPopularity.addEventListener("click", () => {
  products.sort((a, b) => b.populariteit - a.populariteit);
  renderProducts(products);
});

Kern van de les

HTML geeft structuur. JavaScript verandert de toestand.

Een pagina wordt een applicatie zodra gebruikersacties gedrag en data op het scherm kunnen veranderen. Events verbinden die gebruikersactie met je JavaScript.
