Les 3 · JavaScript (ES6+) en de DOM

Van HTML naar interactie.

Twee opdrachten uit de les. Links zie je de werkende demo; rechts zie je de JavaScript-code en het relevante stukje HTML. Let vooral op hoe selectors, id's en events de twee met elkaar verbinden.

01 · DOM-manipulatie

Selecteren, aanpassen, maken en verwijderen

JavaScript zoekt elementen uit de HTML op via bijvoorbeeld #demo-title en #output. Daarna kan het de DOM aanpassen: tekst veranderen, styling wijzigen of nieuwe elementen toevoegen.

Original heading

Some text.

JavaScript

JavaScript

// De selector verwijst naar het id uit de HTML.
const title = document.querySelector("#demo-title");
const description = document.getElementById("demo-description");
const output = document.querySelector("#output");

// JavaScript verandert bestaande DOM-elementen.
title.textContent = "Hello World!";
description.innerHTML = "De DOM is <strong>dynamisch</strong>.";
title.style.color = "#076d69";

// Dit element bestaat eerst nog niet in de HTML.
const p = document.createElement("p");
p.textContent = "Dit element is met JavaScript gemaakt.";
output.appendChild(p);

// Hetzelfde DOM-element kan weer worden verwijderd.
p.remove();

Bijbehorende HTML

Waar grijpt JavaScript op aan?

<h3 id="demo-title">Original heading</h3>
<p id="demo-description">Some text.</p>

<!-- JavaScript voegt hier straks een nieuw p-element aan toe. -->
<div id="output"></div>

  Voer opdracht uit
</button>

De koppeling zit vooral in de id's. Bijvoorbeeld id="demo-title" in HTML wordt met querySelector("#demo-title") in JavaScript geselecteerd.

02 · Productenpagina

Data renderen en sorteren

Hier bevat de HTML alleen een lege plek voor de producten en twee knoppen. JavaScript heeft de data, maakt de productkaarten en reageert op de knoppen met addEventListener.

JavaScript

Data → DOM → event

const products = [
  { naam: "Koffie", prijs: 3.20, populariteit: 92 },
  { naam: "Thee", prijs: 2.80, populariteit: 71 },
  // ...meer producten
];

// Selecteer de lege container en de knoppen uit de HTML.
const productList = document.querySelector("#product-list");
const sortPrice = document.querySelector("#sort-price");

function renderProducts(items) {
  productList.innerHTML = "";

  items.forEach((product) => {
    const card = document.createElement("article");
    card.className = "product-card";
    // Vul de kaart en voeg hem aan de container toe.
    productList.appendChild(card);
  });
}

// De klik op de HTML-knop start deze JavaScript-functie.
sortPrice.addEventListener("click", () => {
  products.sort((a, b) => a.prijs - b.prijs);
  renderProducts(products);
});

De route: HTML maakt de knop en container → JavaScript selecteert ze → addEventListener luistert naar de klik → sort() verandert de volgorde → renderProducts() bouwt de DOM opnieuw op.

Kern van de les

HTML geeft structuur. JavaScript maakt die structuur interactief.

De DOM is de verbinding. JavaScript selecteert HTML-elementen uit de DOM, luistert naar events en kan daarna inhoud, eigenschappen en de structuur van de pagina veranderen.
