HTML beschrijft de inhoud, CSS bepaalt de presentatie en JavaScript kan de toestand van de pagina veranderen.

01 · Statisch

De inhoud staat al in de HTML

Deze titel en tekst blijven zichtbaar wanneer JavaScript wordt uitgeschakeld. De browser leest de HTML en past daarna de CSS toe. 

<h2>De inhoud staat al in de HTML</h2><p>Dit is statische inhoud.</p>

02 · Video

Een videospeler met semantische HTML

<video> beschrijft een videospeler; <source> geeft het mediabestand en bestandstype aan. De browser verzorgt de bediening, zonder eigen JavaScript.

Bron: MDN-videovoorbeeld (CC0). Open het externe MP4-bestand als afspelen niet lukt. Internet is nodig. 

<!-- De bezoeker start de video zelf: geen autoplay. -->
<video controls preload="metadata" playsinline width="960" height="540">
  <!-- source noemt de externe bron; type vertelt welk formaat dit is. -->
  <source
    src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4"
    type="video/mp4">
  Je browser ondersteunt deze videospeler niet.
</video>
<!-- controls: afspelen, pauze en andere browserbediening.
     preload="metadata": vraag vooraf alleen video-informatie op.
     playsinline: speel op mobiel binnen de pagina. -->

Gebruik bij een video met spraak ook ondertiteling via <track kind="captions">. Zet relevante visuele informatie daarnaast in een tekstbeschrijving.

03 · Formulier

Een formulier met duidelijke betekenis

<form> bundelt invoervelden. Elk veld heeft een zichtbaar <label>; for verwijst naar het id van het veld. <fieldset> groepeert velden en <legend> geeft die groep een naam.

Alle velden zijn verplicht. Gebruik verzonnen gegevens: dit lesvoorbeeld controleert de invoer alleen in je browser en verstuurt of bewaart niets.

Jouw oefenbericht

Bijvoorbeeld student@example.com. 

<!-- Vereenvoudigde structuur van het voorbeeld hierboven. -->
<form>
  <fieldset>
    <legend>Jouw oefenbericht</legend>

    <!-- for verwijst naar id: label en invoer horen bij elkaar. -->
    <label for="email">E-mailadres (verplicht)</label>
    <input id="email" name="email" type="email"
           autocomplete="email" required>

    <!-- name is de veldnaam bij een echte verzending.
         type="email" controleert de vorm van het adres.
         autocomplete helpt bij automatisch invullen.
         required maakt het veld verplicht. -->
  </fieldset>
  <button type="submit">Controleer het formulier</button>
</form>

/* JavaScript houdt de verzending in deze demo tegen: */
form.addEventListener("submit", (event) => {
  event.preventDefault(); // Geen netwerkverzoek of paginawissel.
});

Probeer eerst lege velden of een ongeldig e-mailadres. De browser geeft feedback bij het veld. In een echte toepassing stel je ook de bestemming (action) en verzendmethode (method) in en controleert de server de invoer opnieuw.

04 · Box-model

Dezelfde CSS-breedte, een ander totaal

Waarom handig? Met box-sizing: border-box kun je een invoerveld width: 100% geven en padding toevoegen, zonder dat het daardoor breder wordt dan zijn container. Padding en border vallen binnen die 100%.

Beide blokken hebben width: 280px, padding: 32px en border: 16px. Bij content-box komen padding en border erbij; border-box houdt het totaal op 280 px.

content-box
breedte geldt alleen voor content
totaal meten…
border-box
padding en border tellen mee
totaal meten… 
.measure-box {
  width: 280px;  /* De opgegeven CSS-breedte. */
  padding: 32px; /* Binnenruimte aan elke kant. */
  border: 16px solid coral; /* Rand aan elke kant. */
}

.content-box-demo {
  box-sizing: content-box; /* 280px geldt alleen voor de inhoud. */
}
/* Totale breedte: 280 + 32 + 32 + 16 + 16 = 376px. */

.border-box-demo {
  box-sizing: border-box; /* Padding en border vallen binnen 280px. */
}
/* Totale breedte: 280px.
   Voor de inhoud blijft 280 - 32 - 32 - 16 - 16 = 184px over. */

05 · Flexbox

Eén richting, meerdere verdelingen

De container heeft display: flex. Kies hoe de vrije ruimte over de horizontale hoofdas wordt verdeeld. Met flex-direction: row regelt align-items de verticale dwarsas.

.flex-stage {
  display: flex; /* Zet de blokken naast elkaar. */
  flex-direction: row; /* De hoofdas loopt horizontaal. */
  justify-content: flex-start; /* Horizontale verdeling. */
  align-items: center; /* Verticale uitlijning. */
  gap: 0.8rem; /* Ruimte tussen de blokken. */
  min-height: 10rem; /* Extra hoogte maakt verticaal uitlijnen zichtbaar. */
}

Variant · Flexibele breedtes

Twee gelijk, één dubbel, één volle rij

A en B krijgen ieder één deel, C krijgt twee delen. Flexbox trekt eerst de twee gaps van de beschikbare rijbreedte af en verdeelt de rest in 1 : 1 : 2. D begint op de volgende rij en vult die helemaal.

A1 deel
B1 deel
C2 delen
D100% · volledige rij

Bij een rij van 800 px en een gap van 16 px blijft 768 px over: A = 192 px, B = 192 px en C = 384 px. D = 800 px: op zijn eigen rij zijn er geen horizontale gaps om af te trekken. 

.ratio-flex {
  display: flex;    /* Zet de blokken naast elkaar. */
  flex-wrap: wrap; /* Laat het volle blok naar een eigen rij gaan. */
  gap: 1rem;      /* Ruimte tussen blokken; meestal 16px. */
}

/* A, B en C hebben allemaal de class ratio-tile. */
.ratio-flex > .ratio-tile {
  flex: 1 1 0;
  /*    ↑
        Het EERSTE getal is de groeifactor: 1 deel.
        De laatste 0 laat de verdeling bij breedte 0 beginnen. */
  min-width: 0; /* Lange inhoud mag het blok niet breder dwingen. */
}

/* C heeft daarnaast de class ratio-double. */
.ratio-flex > .ratio-double {
  flex-grow: 2; /* Overschrijft voor C de groeifactor: 2 delen. */
}

/* A: 1 + B: 1 + C: 2 = 4 delen op deze rij.
   Na aftrek van de twee gaps krijgt:
   A een kwart, B een kwart en C de helft van de ruimte. */

.ratio-flex > .ratio-full {
  flex: 0 0 100%; /* D vult een eigen rij en telt hierboven niet mee. */
}
/* Flexbox verdeelt de ruimte per rij.
   Het aantal delen is de SOM van de groeifactoren,
   niet het aantal blokken: hier 3 blokken, maar 4 delen. */

flex: 1 1 0 betekent: groeien met factor 1, krimpen met factor 1 en beginnen bij breedte 0. De buitenste blokken hebben geen padding of border; de tekst krijgt ruimte via een binnenste span. Zo is C ook werkelijk twee keer zo breed als A.

06 · CSS Grid

Vier blokken, twee richtingen

Deze container gebruikt display: grid met twee kolommen en twee rijen. justify-content verdeelt het hele raster horizontaal; align-content verticaal. De vaste sporen laten vrije ruimte over, zodat je het verschil ziet. justify-items en align-items zouden juist de blokken binnen hun eigen cel uitlijnen.

display: grid; /* Maak een raster. */
grid-template-columns: repeat(2, 4rem); /* Twee kolommen van 4rem. */
grid-template-rows: repeat(2, 4rem);    /* Twee rijen van 4rem. */
gap: 0.8rem;            /* Ruimte tussen de blokken. */
justify-content: start; /* Hele raster horizontaal aan het begin. */
align-content: start;   /* Hele raster verticaal aan het begin. */
/* rem volgt de lettergrootte van html: meestal 1rem = 16px. */

Variant · Kolommen in verhouding

Een brede kolom naast twee smalle

Met 2fr 1fr 1fr verdeelt Grid de breedte na aftrek van de twee gaps in 2 : 1 : 1. A is twee keer zo breed als B en C. D loopt daaronder van de eerste tot de laatste rasterlijn.

A2 delen
B1 deel
C1 deel
D1 / -1 · alle kolommen

Bij 800 px en een gap van 16 px worden de kolommen 384, 192 en 192 px. Het brede blok D beslaat 800 px, inclusief de ruimte van de tussenliggende gaps. 

.ratio-grid {
  display: grid; /* Maak een raster van rijen en kolommen. */

  /* fr = een deel van de ruimte na aftrek van de gaps.
     minmax(0, 2fr) = brede kolom, met minimum 0.
     repeat(2, ...) = twee gelijke smalle kolommen.
     Samen geeft dit de verhouding 2:1:1. */
  grid-template-columns: minmax(0, 2fr) repeat(2, minmax(0, 1fr));

  gap: 1rem; /* Ruimte tussen rijen en kolommen; meestal 16px. */
}

/* > selecteert alleen directe kinderen met class ratio-full. */
.ratio-grid > .ratio-full {
  grid-column: 1 / -1; /* Van eerste tot laatste rasterlijn. */
}
/* Dit blok beslaat alle kolommen, inclusief de gapruimte.
   Voorbeeld: 800px - 2 gaps van 16px = 768px.
   Kolommen: 384px, 192px, 192px. Het volle blok: 800px. */

minmax(0, ...) laat de kolommen ook op kleine schermen krimpen. Dit voorbeeld verdeelt kolombreedtes; grid-column: span 2 zou twee kolommen én de gap ertussen beslaan.

07 · CSS-animatie

Een kleine beweging met CSS

Deze SVG tekent scherpe vectorvormen. De stip beweegt subtiel heen en terug met CSS. De drie kaarten op de homepage bewegen kort zodra ze in beeld komen. De animaties stoppen vanzelf en blijven uit bij de systeeminstelling ‘minder beweging’. 

/* Eén korte animatie; geen eindeloze beweging. */
.code-motion-dot { animation: code-travel 2.4s ease-in-out 1; }
@keyframes code-travel {
  0%, 100% { transform: translateX(0); }
  50% { transform: translateX(48px); }
}
/* Respecteer de voorkeur voor minder beweging. */
@media (prefers-reduced-motion: reduce) {
  .code-motion-dot { animation: none; }
}

09 · Toegankelijkheid

Bekijk, verklaar en verbeter

WAVE: fouten visueel uitleggen

Installeer de officiële WAVE-browserextensie voor Chrome, Edge of Firefox. Open een pagina en activeer WAVE. Bekijk Errors, Contrast, Alerts en Structure; selecteer een icoon om het betreffende element en de uitleg te zien.

Lesopdracht: verwijder tijdelijk het alt-attribuut van een foto in Developer Tools en voer WAVE opnieuw uit. Herstel daarna alt="" voor een decoratieve foto. Een informatieve afbeelding krijgt juist een beschrijving van de relevante inhoud. Een waarschuwing vraagt beoordeling; deze is niet automatisch een fout.

Lighthouse: technische eindcheck

Open de pagina in Chrome, open Developer Tools en kies Lighthouse. Selecteer Accessibility, Performance, Best Practices en SEO, kies Mobile of Desktop en start de analyse. Vergelijk het rapport vóór en na een verbetering. Uitleg en installatie van Lighthouse.

HTML en handmatige controle

Controleer elke pagina met de W3C Nu HTML Checker. Gebruik Tab, Shift+Tab, Enter en Spatie: bereik de skiplink, filters en demo-opties en controleer de zichtbare focus. Test ook 200% zoom en een smal scherm. Een automatische score bewijst geen volledige toegankelijkheid.
