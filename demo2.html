Les 3 · JavaScript (ES6+) en de DOM

Van HTML naar interactie.

Eerst de belangrijkste begrippen uit de presentatie, daarna twee opdrachten om ze toe te passen.

Eerst · Begrippen uit de presentatie

Wat betekenen de lastigere stukken?

01 · JAVA VS JAVASCRIPT

Statisch versus dynamisch getypeerd

// Java
int age = 25;
// JavaScript
let value = 25;
value = "Hallo";

Java is statically typed; JavaScript dynamically typed.

02 · CONST, LET & SCOPE

Block scope en opnieuw toewijzen

let x = 10;
x = 20; // mag
const numbers = [3, 4];
numbers.push(5); // mag
numbers = [4, 5]; // fout

let en const hebben block scope. Een const mag niet opnieuw worden toegewezen.

03 · ARROW / LAMBDA

Een functie korter schrijven

function add(a, b) { return a + b; }
add(10, 5);
const addArrow = (a, b) => a + b;
addArrow(10, 5);

04 · ANONIEME FUNCTIE

button.addEventListener("click", () => {
  title.textContent = "Hallo!";
});

De anonieme arrow function is hier direct de callback en event handler.

05 · EVENTS, LISTENER & HANDLER

function handleClick(event) {
  console.log(event.target);
}
button.addEventListener("click", handleClick);

Event = gebeurtenis. Listener = registratie. Handler = functie die wordt uitgevoerd. De browser geeft het event-object aan de handler.

06 · FOREACH

products.forEach(product => console.log(product.naam));

07 · SORT

products.sort((a, b) => a.prijs - b.prijs); // laag → hoog
products.sort((a, b) => b.prijs - a.prijs); // hoog → laag

08 · JSON & OBJECT

const json = '{"naam":"Marijn"}';
const persoon = JSON.parse(json);
persoon.naam;

JSON is tekst. Na JSON.parse() werk je met JavaScript-data.

Opdracht 01 · DOM-manipulatie

Selecteren, aanpassen, maken en verwijderen

Onderstaande HTML sluit nu letterlijk aan op de selectors uit de opdracht: #title en #description.

Original heading

Some text.

JavaScript uit de opdracht

const h1 = document.querySelector("#title");
const ookH1 = document.getElementById("title");

h1.textContent = "Hello World!";
h1.innerHTML = "Hello <b>World!</b>";
h1.style.color = "red";

const p = document.createElement("p");
p.textContent = "Hello!";
document.body.appendChild(p);
p.remove();

Bijbehorende HTML uit de opdracht

<h1 id="title">Original heading</h1>
<p id="description">Some text.</p>

Belangrijk: Some text. is de bestaande <p id="description">. De variabele p in JavaScript verwijst naar een nieuw p-element dat met createElement() wordt gemaakt. Daarom verwijdert p.remove() niet de bestaande “Some text.”.
