Les 3 · JavaScript (ES6+) en de DOM

Van HTML naar interactie.

Twee opdrachten uit de les. Links zie je de werkende demo; rechts zie je JavaScript en het relevante stukje HTML. Let vooral op hoe selectors, id's en events de twee verbinden.

01 · DOM-manipulatie

Selecteren, aanpassen, maken en verwijderen

JavaScript zoekt elementen uit de HTML op. Daarna kan het via de DOM tekst, styling en structuur aanpassen.

Original heading

Some text.

JavaScript

// Selecteer elementen via hun HTML-id.
const title = document.querySelector("#demo-title");
const description = document.getElementById("demo-description");
const output = document.querySelector("#output");

title.textContent = "Hello World!";
description.innerHTML = "De DOM is <strong>dynamisch</strong>.";
title.style.color = "#076d69";

const p = document.createElement("p");
p.textContent = "Dit element is met JavaScript gemaakt.";
output.appendChild(p);
p.remove();

Bijbehorende HTML

<h3 id="demo-title">Original heading</h3>
<p id="demo-description">Some text.</p>
<div id="output"></div>
<button id="run-dom" type="button">Voer opdracht uit</button>

id="demo-title" wordt geselecteerd met querySelector("#demo-title").

02 · Productenpagina

Data renderen en sorteren

HTML levert de knoppen en een lege container. JavaScript bevat de data, maakt elementen en reageert op events.

JavaScript

const products = [
  { naam: "Koffie", prijs: 3.20, populariteit: 92 },
  { naam: "Thee", prijs: 2.80, populariteit: 71 }
];
const productList = document.querySelector("#product-list");
const sortPrice = document.querySelector("#sort-price");
function renderProducts(items) {
  productList.innerHTML = "";
  items.forEach((product) => {
    const card = document.createElement("article");
    card.className = "product-card";
    productList.appendChild(card);
  });
}
sortPrice.addEventListener("click", () => {
  products.sort((a, b) => a.prijs - b.prijs);
  renderProducts(products);
});

Bijbehorende HTML

<button id="sort-price" type="button">Sorteer op prijs</button>
<button id="sort-popularity" type="button">Sorteer op populariteit</button>
<div id="product-list"></div>
<script src="js/demo2.js" defer></script>

Route: HTML → selector → event → functie → DOM aanpassen.

Extra · Begrippen uit de code

Wat betekenen de lastigere stukken?

Je hoeft de syntax niet allemaal uit je hoofd te kennen; begrijp vooral wat er gebeurt.

01 · ARROW / LAMBDA

Dezelfde functie, korter geschreven

function add(a, b) {
  return a + b;
}
add(10, 5); // 15

const addArrow = (a, b) => a + b;
addArrow(10, 5); // 15

// Alleen de anonieme arrow function:
(a, b) => a + b;

De arrow function zelf is (a, b) => a + b. Door hem in addArrow te bewaren kun je hem later aanroepen.

02 · ANONIEME FUNCTIE

Een functie zonder naam

button.addEventListener("click", () => {
  title.textContent = "Hallo!";
});

De functie wordt direct meegegeven aan addEventListener en hoeft daarom niet eerst een eigen naam te krijgen.

03 · EVENT OBJECT

Informatie over wat gebeurde

document.addEventListener("keydown", (event) => {
  console.log(event.key);
  console.log(event.target);
});

De browser geeft het event-object aan de handler met informatie over de gebeurtenis.

04 · FOREACH

Doe iets voor elk item

products.forEach((product) => {
  console.log(product.naam);
});

forEach loopt door een array. De functie bepaalt wat er met ieder item gebeurt.

05 · SORT CALLBACK

Hoe moet de array sorteren?

products.sort((a, b) => a.prijs - b.prijs);
// negatief: a vóór b
// positief: b vóór a

De functie die je aan sort meegeeft bepaalt de volgorde.

06 · JSON, OBJECT & COMMUNICATIE

JSON is tekst; eerst omzetten om properties te gebruiken

// JSON zoals je die bijvoorbeeld van een API ontvangt:
const json = '{"naam":"Marijn","leeftijd":44}';

json.naam; // ❌ werkt niet: json is hier gewoon tekst (string)

// JSON-tekst omzetten naar een JavaScript-object:
const persoon = JSON.parse(json);

persoon.naam;     // ✅ "Marijn"
persoon.leeftijd; // ✅ 44

// Andersom: JavaScript-object omzetten naar JSON-tekst:
const terugNaarJson = JSON.stringify(persoon);

Communicatie: een server/API kan JSON-data versturen. In JavaScript zet je die om naar een object voordat je bijvoorbeeld persoon.naam gebruikt. Andersom kan JSON.stringify() een JavaScript-object omzetten naar JSON-tekst voor opslag of verzending.

07 · CONST VS LET

Een const mag je niet opnieuw toewijzen

const x = 10;
x = 20; // ❌ opnieuw toewijzen

let score = 10;
score = 20; // ✅ mag

const numbers = [3, 4];
numbers.push(5); // ✅ dezelfde array aanpassen
numbers[0] = 10; // ✅ dezelfde array aanpassen
numbers = [4, 5]; // ❌ andere array toewijzen

Bij const mag je de variabele niet opnieuw toewijzen. Bij een array of object mag de inhoud van hetzelfde object wél veranderen.

Kern van de les

HTML geeft structuur. JavaScript maakt die structuur interactief.

De DOM is de verbinding. JavaScript selecteert HTML-elementen, luistert naar events en verandert daarna inhoud of structuur.
